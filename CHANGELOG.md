# Changelog

## [3.0.0]

- Paired companion for backend 3.0.0. Website/page events retain their page,
  source and device provenance for the backend's Analytics filters.
- Shared generated schema types cover the starter's current migrations and
  domain helper aliases. Existing Homes generate from their own complete schema.
- Setup/upgrade guides preserve member customisations and distinguish official
  001–899 migrations from new member 900–999 files. No new frontend migration.
- Node 22+, Next.js 16. Existing website design, content and routes remain owned
  by the member; this release does not prescribe a Money screen.
